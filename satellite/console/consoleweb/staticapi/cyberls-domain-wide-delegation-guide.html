Navigational Steps to Update Domain-Wide Delegation in Google Admin For CyberLS

To enable auto-sync and allow scheduled mail backups, you must configure Domain-Wide Delegation in your Google Admin account.

Follow the steps below from the Super Admin account connected to your Google Workspace.

Step 1 — Open Google Admin Console

Go to: https://admin.google.com/ and sign in with your Super Admin account.

Step 2 — Navigate to Domain-Wide Delegation

  1. From the Admin Console dashboard, go to: Security → API Controls
  2. Click on Domain-wide Delegation

Step 3 — Add a New API Client

  1. Click Add new
  2. Enter the following details:
Field Value
Client ID 112742432393142971486
OAuth Scopes https://www.googleapis.com/auth/calendar.readonly,https://www.googleapis.com/auth/contacts.readonly,https://www.googleapis.com/auth/drive.readonly,https://www.googleapis.com/auth/gmail.readonly,https://www.googleapis.com/auth/photoslibrary.readonly,https://www.googleapis.com/auth/gmail.insert,https://www.googleapis.com/auth/drive.file,https://www.googleapis.com/auth/calendar.events,https://www.googleapis.com/auth/contacts,https://www.googleapis.com/auth/photoslibrary.appendonly
  1. Click Authorize

Step 4 — Verification

Once authorized, the client ID will appear in the Domain-wide Delegation list. This confirms the configuration is complete.
