Login to the CyberLs using the Authentication process

  1. Navigate to the cyberLs Homepage using the URL “https://outh365.cyberls.com/”
  1. Click on the Login button in the Homepage or Use the link to navigate to the Login page. “https://outh365.cyberls.com/connect”.
  1. Click on the “Continue with Microsoft” button and you will be asked to authenticate using the Microsoft account as shown below
  1. Once the account is authenticated successfully you will be redirected to the Dashboard page as shown below. Confirming the Login was successful.

Login Using the Email and Password

  1. Navigate to the cyberLs Homepage using the URL “https://outh365.cyberls.com/”
  1. Click on the Login button in the Homepage or Use the link to navigate to the Login page. “https://outh365.cyberls.com/login”.
  1. Fill in the CyberLs User credentials your Microsoft mail id and the password associated with the cyberLs used while trying to signup into the CyberLs to Login.
  2. Once Logged in using the Email and the password you will be taken to the Dashboard as shown below. Confirming the Login was successful.

Login Using the Email and Password With 2-FA enabled

  1. Navigate to the cyberLs Homepage using the URL “https://outh365.cyberls.com/”
  1. Click on the Login button in the Homepage or Use the link to navigate to the Login page. “https://outh365.cyberls.com/login”.
  1. Fill in the CyberLs User credentials, your Microsoft mail id and the password associated with the cyberLs used while trying to signup into the CyberLs to Login and click on the Sign-in Button.
  2. Now you will be asked to enter the 2FA code or Use the recovery Code to login.
  1. Once Logged in using the Email and the password and 2FA Code you will be taken to the Dashboard as shown below. Confirming the Login was successful.
